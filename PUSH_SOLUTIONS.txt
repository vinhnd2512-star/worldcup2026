================================================================================
❓ NẾU VẪN BÁO LỖI
================================================================================

Lỗi: "python not found"
→ Cài Python: https://www.python.org/downloads/
→ Tích vào "Add Python to PATH"

Lỗi: "git not found"
→ Cài Git: https://git-scm.com/download/win

Lỗi: Khác
→ Chạy: git status
→ Chạy: git log --oneline -5
→ Nếu có commit, thì chạy: git push
